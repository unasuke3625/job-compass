# Job Compass

就職活動における企業情報・選考情報を一元管理するWebアプリケーションです。

## 概要

就職活動を進める中で、応募企業、選考状況、締切、面接日時などの情報が増え、
複数のサービスやメモに情報が分散して管理しづらいという課題を感じました。

そこで、自分自身の就職活動を効率化するため、
企業情報と選考情報を一元管理できるWebアプリ「Job Compass」を開発しました。

単に情報を保存するだけではなく、
「次に何の選考があるか」「締切が近いものは何か」を確認しやすい設計を目指しています。

## 主な機能

### ユーザー管理
- ユーザー新規登録
- ログイン
- ログアウト
- ユーザーごとのデータ分離

### 企業情報管理
- 企業情報の登録
- 企業情報の一覧表示
- 企業情報の編集
- 企業情報の削除

### 選考情報管理
- 選考情報の登録
- 選考情報の一覧表示
- 選考情報の編集
- 選考情報の削除
- 企業による絞り込み
- 選考ステータスによる絞り込み
- 締切日・実施日を考慮した並び替え

### カレンダーによるスケジュール可視化
登録した選考予定をカレンダー上に表示することで、
締切や面接日程を直感的に把握できるようにした

## データベース構成

主に以下の3種類のデータを管理しています。

- `users`：ユーザー情報
- `companies`：企業情報
- `selections`：選考情報

企業情報をユーザーと紐付けることで、
ログインしているユーザー自身のデータのみ操作できるようにしています。

また、選考情報と企業情報を関連付けることで、
企業ごとに複数の選考情報を管理できるようにしています。

## 工夫した点

### 1. 実際の自分の課題をもとに設計

学習用のサンプルをそのまま作るのではなく、
実際に自分が就職活動をする中で感じた
「企業・選考情報が増えると管理が煩雑になる」という課題から開発しました。

利用場面を想定しながら、
企業情報と選考情報を分けて管理する構成にしています。

### 2. ユーザーごとのデータ分離

ログインユーザーの `user_id` を利用して、
他のユーザーの企業情報を取得・操作できないようにしています。

選考情報を登録する際にも、
選択された企業がログインユーザー自身の企業であることを確認しています。

### 3. SQLインジェクション対策

PDOのプリペアドステートメントを利用し、
SQLに値を直接埋め込まないようにしています。

### 4. パスワードの安全な保存

パスワードを平文で保存せず、
PHPの `password_hash()` を利用してハッシュ化しています。

### 5. XSS対策

画面上にユーザー入力値を表示する際には、
`htmlspecialchars()` を使用してエスケープ処理を行っています。

### 6. 就活で使いやすい一覧表示

選考情報は、締切日または実施日を基準として
日付が近いものから確認できるようにしています。

また、企業や選考ステータスによる絞り込みにも対応しています。

## セキュリティ

以下の対策を実装しています。

- PDOプリペアドステートメントによるSQLインジェクション対策
- `password_hash()` によるパスワードのハッシュ化
- `htmlspecialchars()` によるXSS対策
- ログインユーザー単位でのデータアクセス制御
- DB接続情報を `.gitignore` でGit管理対象外に設定

DB接続設定については、
`includes/db.example.php` を参考にローカル環境で設定します。
